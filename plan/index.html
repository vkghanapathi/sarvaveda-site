Ownership

The eight working groups

Each unit is owned by one group, so there is a single convenor accountable for it. Assignment follows the track, not the individual unit, which means new work inherits a group instead of waiting to be allocated. The Tech Team is not a ninth group — it carries the units whose deliverable is software.
